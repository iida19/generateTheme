# Illustration Theme Generator

JavaとServletとJSPで作成したイラストのお題作成アプリです。

## 機能
- ランダムなお題生成
- 難易度選択（4段階）
- 最新3件分の履歴保存、表示
- 最大10件のお気に入り保存、表示
- CSVファイル読み込み、書き込み
- 起動時の履歴・お気に入り復元

## 使い方
1. Tomcatを起動
2. ブラウザでアプリへアクセス
3. メニューを選択
4. お題の難易度を選択
5. お題を確認
6. お気に入りに保存
7. 履歴を確認
8. お気に入りに保存したお題を確認
